# WeekendReady brand kit

## Logo
A winding road running diagonally from bottom-left to top-right, with a dashed white centre line. Three dots sit on the bends and the road wraps around each one:
- green – start
- yellow – stop
- red – finish

Background of the icon: Trail Blue. Variants: horizontal, on dark, vertical, icon only, icon on light background. Text in the SVG is converted to outlines.

## Colours
| Name | HEX | Use |
|---|---|---|
| Night Ink | `#142033` | text, dark backgrounds |
| Trail Red | `#D2232A` | finish, accents, calls to action |
| Paper | `#EEF1EE` | light backgrounds |
| Trail Blue | `#1D5FB8` | icon background, links |
| Trail Green | `#13804A` | start, success |
| Trail Yellow | `#E3A600` | stops, highlights |

## Fonts
- **Poppins Bold** – headings and logo
- **Poppins Regular** – body text

## Personality
Explorer + Excitement + Friendly.
Values: Wellbeing, Activity, Tourism.
